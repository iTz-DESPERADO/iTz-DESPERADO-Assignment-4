# Academy Schedule Analyzer - Assignment Work

## Run

From this folder, with the .NET 10 SDK:

```powershell
dotnet run --project AcademyScheduleAnalyzer
```

The menu uses Up/Down, Enter, and Escape. Text input supports Backspace and cancellation with Escape. Long output screens scroll with Up/Down.

## Included functionality

- Display, search, sorted/reversed copies, index lookup, existence checks, and selection by index.
- Duration totals, averages, shortest/longest values, and a sorted duration copy.
- Session date details, five date/time formats, calculated end times, date differences, past/upcoming classification, and nearest future session.
- Strict date validation, integer parsing, duration validation, and specific exception handling.
- Equivalent string and StringBuilder reports.
- Array.Find, Array.FindIndex, Array.Copy, ref, out, reference-type mutation without ref, and params examples.
